대상 TTS(VoxCPM2)는 중국어를 **wetext로 정규화**하므로 wetext가 실제 비교 기준입니다.

## wetext가 틀리는 곳 (모두 50구간)

1. **번호·코드를 큰 수로 읽음:**
   - 邮编100080 → 十万零八十, 验证码123456 → 十二万…
   - 301房间, CA1234, G1234次, 学号, 分机, 快递单号, +86 → 正八十六
   - 110·120·119와 휴대폰 번호는 맞습니다.
2. **二/两:** 第2名 → 第两名, 2点 → 二点, 2次 → 二次, 2倍 → 二倍, 第2季度 → 第两季度, 2部 → 二部
3. **범위 표기:** 전각 물결 `～`, 긴 대시 `—`, 第3-5章 → 三减五, 5%-8%·50%-60% → 百分之负…
4. **수식:** 10÷2 → 十除二(뜻이 반대), x=3의 `=`, 2^10, 10², √4
5. **단위 기호:** V·Hz·W·g를 읽지 않음, hPa → 小时Pa
6. **쉼표 큰 수:** 12,345 → 十二,三百四十五, ¥1,280
7. **하이픈 영숫자:** COVID-19·GPT-4 → 负十九·负四
8. **시각·기록·점수:** 0:30 → 零比三十, 2:05:30 → 两点零五分…, 21:19(점수) → 二十一点十九分
9. **그 밖:** 5‰, ½, 1又1/2, HK$100 → HK一百美元, ₩10,000, 1998那年 → 一千九百九十八

## 판단

- wetext는 중국어에서 강합니다(85.5%, 일본어 76.9%보다 높음). 날짜·소수·음수·서수·어림수는 이 평가셋에서 모두 맞습니다.
- 틀리는 곳은 우리 엔진이 한국어·일본어에서 이미 다루는 유형에 몰려 있습니다. 번호 문맥 단서, 범위 기호, 단위 기호, 영숫자, 수식, 쉼표 자릿수가 그렇습니다.
- 그래서 중국어 팩은 이 평가셋에서 95% 이상을 목표로 할 만합니다. 1단계 진행을 권합니다.
- **1단계에서 할 것:**
  - 한자만 있는 문장을 중국어로 판별(일본식 한자는 일본어 근거)
  - 숫자·二/两·연도·날짜·시각·금액·단위·비율
  - 위 빈틈 1~9
- **나중 단계:** 평가셋을 1,000문장으로 늘리고, 운영 판단은 일본어와 같은 기준(원어민 검수, TTS 청취 비교)으로 합니다.
