# 한국어 범위 읽기 (v0.24)

`2~3만 원`, `3~4개`, `3~5kg`처럼 물결표(또는 하이픈)로 적은 수의 범위를 읽는 규칙이다.
사용자 결정(2026-09-30)과 AI Hub 159 참조 142,255문장의 실측에 따른다.

## 1. 표준과 근거

- **읽는 법에 대한 공식 규정은 없다.** 한글 맞춤법의 문장 부호 규정은 물결표를 "기간·거리·범위"에
  쓴다고만 정한다.
- **이웃한 두 수는 어림수 단어로 읽는다.** 표준국어대사전에 어림수가 단어로 올라 있다.
  - 한자어: 이삼, 삼사, 사오, 오륙…
  - 고유어: 한두, 두세, 서너, 대여섯…
- **참조 데이터(범위 뒤에 단위가 붙은 경우):**

| 경우 | 참조 방식 | 건수 |
|---|---|---:|
| 이웃한 한 자리 수 (`2~3년`, `3~4개`) | 붙여 읽기 (이삼 년, 서너 개) : 앞 수에 단위 없이 "에서" | 663 : 172 |
| 이웃한 십 단위 (`20~30대`) | 붙여 읽기 (이삼십 대) : "에서" | 463 : 108 |
| 그 밖의 범위 (`3~5kg`, `18~25세`) | 앞 수에 단위 없음 (삼에서 오 킬로그램) : 단위 반복 | 1,466 : 6 |
| 두 수 모두 단위를 적음 (`3개~4개`) | 적은 그대로 단위 반복 (세 개에서 네 개) | (적힌 대로) |
| 이웃한 수 + 미터법 단위 (`1~2kg`) | 붙여 읽기 : "에서" | 17 : 20 |

## 2. 규칙

적용 대상은 단위가 있는 범위(수량·금액·퍼센트·셈단위·시각)뿐이다. 단위 없는 `2~3`은 "이에서 삼"
그대로다. `~` 외에 하이픈 범위(`3-5개`)도 같은 규칙을 따른다.

1. **두 수 모두 단위를 적었으면 적은 대로 읽는다.**
   - `3개~4개` → 세 개에서 네 개
   - `₩1,000~₩2,000` → 천 원에서 이천 원
   - `B1~B3층` → 지하 일 층에서 지하 삼 층
2. **이웃한 두 수는 붙여 읽는다.** `k·10ⁿ ~ (k+1)·10ⁿ` 모양이 대상이다.
   - 고유어 셈단위(개·명·시간·시·번…)의 한 자리 수는 고유어 어림수: `3~4개` → 서너 개, `2~3시` → 두세 시
   - 그 밖에는 한자어: `2~3만 원` → 이삼만 원, `4~5억` → 사오억, `20~30명` → 이삼십 명, `300~400명` → 삼사백 명,
     `6~7월` → 육칠 월
   - 붙여 읽지 않는 경우:
     - `k = 1`이면서 십 이상인 범위(`10~20%`, `1~2만 원`)
     - 미터법 단위(`1~2kg` → 일에서 이 킬로그램)
     - 서수(`1~3번째` → 첫 번째에서 세 번째)
     - 소수, 음수
3. **그 밖의 범위는 뒤 수에만 단위를 붙인다.**
   - `3~5kg` → 삼에서 오 킬로그램, `18~25세` → 십팔에서 이십오 세
   - 고유어 셈단위는 앞 수에도 단위를 붙인다: `2~5개` → 두 개에서 다섯 개, `2~4시간` → 두 시간에서 네 시간
     (소유자 결정 2026-10-23; 이전: 둘에서 다섯 개). 한자어 단위는 그대로 앞 수만 읽는다: `2~4층` → 이에서 사 층
   - 앞 수를 규모 없이 적었으면 적은 대로 읽는다: `1~3만 원` → **일**에서 삼만 원, `3~5천만대` → 삼에서 오천만 대
   - 뒤 수가 소수면 값대로 읽는다: `1~1.5만 원` → 만에서 만 오천 원
   - 규모를 양쪽에 적었으면 규모는 유지한다: `1억~2억 원` → 일억에서 이억 원
4. **단위별 예외.**
   - 시각은 붙여 읽을 때만 단위를 한 번 쓴다: `2~3시` → 두세 시, `2~4시` → 두 시에서 네 시
     (`range_repeat_unit ko-KR 시 wide`)
   - 앞에 붙는 말이 있는 단위는 그 말을 양쪽에, 단위는 뒤에 한 번 쓴다: `60~70℃` → 섭씨 육십에서 섭씨 칠십 도,
     `2~3 mph` → 시속 이에서 시속 삼 마일 (소유자 결정 2026-10-23; 이전: 시속 이 마일에서 시속 삼 마일).
     영하가 끼면 그대로 둔다(`-5~10℃` → 영하 오 도에서 십 도).
5. **물결표 변형:** 수 사이의 `∼`(U+223C), `～`(U+FF5E), `〜`(U+301C)는 `~`와 같다. 분류용 보기에서만 `~`로
   바꾸므로 원문 위치 정보는 그대로다. 수 사이가 아니면(`감사합니다∼`) 그대로 둔다.

## 3. 리소스

| 행 | 뜻 |
|---|---|
| `policy ko-KR quantity_range_repeat_unit 0` | 기본: 뒤 수에만 단위 (1이면 양쪽) |
| `policy ko-KR range_contract adjacent` | 이웃한 수 붙여 읽기 (`off`로 끔) |
| `range_contract ko-KR sino:1..8`, `native:1..8` | 어림수 형태 (이삼, 오륙 / 한두, 서너…) |
| `range_repeat_unit ko-KR <단위> 0\|1\|wide` | 단위별 예외 (`wide`: 붙여 읽지 않을 때만 반복) |

이전 방식(양쪽에 단위, 붙여 읽기 없음: `2~3만 원` → 이만 원에서 삼만 원)은 고객 프로필
`resources/customers/range-repeat-unit/ko-KR/rules.tsv`로 쓸 수 있다.

## 4. 측정과 계약

- 한국어 벤치마크(보정 variant): 75.39% → **76.84%**. 새로 맞음 2,086, 새로 틀림 15이다.
  - 새로 틀림 15건 중 11건은 참조가 `20~30대`를 "이십에서 삼십 대"로 읽은 것이다.
  - 연령대 범위 전체로 보면 새로 맞음 191, 새로 틀림 10이다.
- 영어 벤치마크 변화는 0이다.
- 계약 `tests/evaluation/ko_range_reading_v24.jsonl` 49건. 결과를 구현 전에 작성했고, 이전 방식 프로필 3건을 포함한다.
- 기존 계약 45행, 테스트 스크립트·웹 예제의 기대값 30곳, 고정 해시 2개는 이 결정에 맞춰 바꿨다. 각 행의 notes에 이전 값을 남겼다.
  - 대부분 `1~2만 원`을 "만 원에서 이만 원"으로, `1~2개`를 "한 개에서 두 개"로 적은 것이다.

## 5. 한계

- `2~3번`처럼 셈단위가 수·번호 양쪽으로 읽히는 경우는 엔진의 기존 판단(한자어)을 따른다: 이삼 번.
- 숫자 묶음 공백(`1 250~2 500원`)이 있는 범위는 적은 그대로 양쪽에 단위를 붙인다.
- 참조의 "이에서 삼만" 식 읽기(이웃한 수 172건)는 옵션으로 두지 않았다.
