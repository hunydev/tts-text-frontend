# 꾸민 글자, 화학식, 악센트 낱말 (2026-10-26)

xvoice5 비교 중 찾은 두 가지 약점(𝟏𝟐𝟑을 읽지 않음, Café를 캐프로 읽음)과 비슷한 사례를 함께 고쳤다. 원인이 서로 달라서 다섯 갈래로 나눴다. 계약 `ko_styled_accent_v117`(30건).

## 1. 수학용 숫자 𝟏𝟐𝟑

- **원인:** 숫자 폭 처리(`src/semantic/numeric_width.c`, [numeric-width.ko.md](numeric-width.ko.md))가 전각 숫자 `１２３`만 ASCII로 바꿨다. SNS의 꾸민 글자에 쓰는 수학용 숫자(U+1D7CE–U+1D7FF: 굵은 𝟏, 이중선 𝟙, 산세리프 𝟣·𝟭, 고정폭 𝟷)는 기호로 남아 아무 규칙도 적용되지 않았다.
- **고친 것:** 같은 처리에 수학용 숫자를 더했다. 토크나이저는 이 문자를 숫자로 보고, 원문 위치(스팬)는 전각 숫자처럼 원문 그대로다. 금액·날짜·시각·전화번호와 영어 문장(Only 𝟓 left → five) 모두 기존 숫자 규칙을 그대로 쓴다.

## 2. 수학용 글자 𝐀𝐁𝐂

- **원인:** 같은 블록의 글자(U+1D400–U+1D6A3)와 그 빈자리를 채우는 글자꼴 기호(ℎ ℂ ℝ ℬ …)가 읽히지 않았다.
- **고친 것:** 전각 글자(Ａ 에이)와 같은 speech 글자 읽기로 넣었다. `resources/languages/{ko-KR,en-US}/rules/speech-math-letters.tsv`(각 676행, `tools/unicode_fallback/math_letters.py`가 생성). 𝐁𝐄𝐒𝐓 → 비이에스티, ℝ → 알, 영어 문장에서는 글자 그대로(SALE). text 출력은 원문을 지킨다. ℓ, K(켈빈 기호), ℹ는 단위·기호라서 넣지 않았다.
- **한계:** 전각 글자처럼 글자 이름으로 읽는다. 꾸민 글자로 쓴 낱말(𝐒𝐚𝐥𝐞)을 낱말로 읽지는 않는다.

## 3. 화학식 (소유자 결정 2026-10-26)

H₂O는 에이치투오로 읽는다. 원소 기호는 글자 이름으로, 개수는 영어 숫자로 읽어 붙인다.

| 입력 | 전 | 지금 |
|---|---|---|
| H₂O, CO₂ | 에이치₂오, 씨오₂ | 에이치투오, 씨오투 |
| H2SO4 | 에이치 이 에스오 사 | 에이치투에스오포 |
| C6H12O6 | 씨 육 에이치 일이 오 육 | 씨식스에이치트웰브오식스 |
| Fe2O3 | 프투오쓰리 | 에프이투오쓰리 |
| x₁, a₁₂ | 엑스₁ | 엑스원, 에이트웰브 |

- 한국어 팩 `chemical_formula`. 모든 기호가 원소여야 한다.
- **화학식으로 보는 조건:** 아래 첨자 개수(₀–₉)가 있으면 화학식이다. ASCII로 쓴 것은 개수가 둘 이상이거나 두 글자 기호(Fe, Ca)가 있을 때만 화학식으로 본다. CO2·B7·K5처럼 기호 하나에 숫자 하나는 원래부터 같은 방식(씨오투, 비세븐)으로 읽고, MP3처럼 원소가 아닌 글자가 섞이면 코드로 둔다.
- **제품 코드와 구별:** 원소 기호로만 된 제품 코드가 많아서(K47YI5124, BC40F28) 한국어 릴리스 벤치마크에서 처음 358문장, 그다음 10문장이 화학식으로 잘못 읽혔다. 그래서 개수는 한두 자리만 받는다. ASCII 화학식은 흔한 원소만 쓰고(B, V, W, Y, U 없음), 0으로 시작하는 개수를 받지 않으며, 번호·코드·모델·품번 뒤에서는 화학식으로 보지 않는다. 이렇게 좁힌 뒤 바뀐 문장은 0이다.
- **개수 읽기:** 10까지는 `english_numeral`, 11–99는 teen·tens 낱말, 그보다 길면 한 자리씩 읽는다.
- **아래 첨자 번호:** 글자 하나에 아래 첨자 번호가 붙은 것(x₁)도 같은 방식으로 읽는다.
- **한계:** 개수 없는 화학식(NaCl)은 낱말로 읽는다(내클). 영어 문장 속 H₂O는 그대로다.

## 4. 표준국어대사전 악센트 원어

- **원인:** 원인은 악센트가 아니었다. 악센트를 뗀 cafe도 캐프였다. 엔진은 악센트를 떼고(café → cafe) 사전을 찾는데 cafe가 없어서 영어 철자 규칙으로 추측했고, 끝의 e를 묵음으로 읽었다. 기존 외래어 표(`stdict_loanwords.tsv`)는 원어가 소문자 영문 3자 이상인 단어만 받아서 café, München, São Paulo가 빠져 있었다.
- **고친 것:** `tools/lexicon/stdict_loanwords.py`가 악센트 원어도 받는다.
  - **한 낱말:** 소문자·대문자 원어 404개(café 카페, Düsseldorf 뒤셀도르프, Zürich 취리히, Bogotá 보고타)를 악센트를 뗀 키로 외래어 표에 넣었다. 기존 영어 원어와 겹치면 기존 것을 쓴다(xylene 자일렌). 악센트를 떼면 다른 영어 낱말이 되는 20개는 뺐다(college는 collège 콜레주가 아니다, loss는 Löss 뢰스가 아니다; CMUdict와 대조해 사람이 고름).
  - **여러 낱말:** 2–4낱말 원어 182개 키(São Paulo 상파울루, Les Misérables 레 미제라블, el Niño 엘니뇨)를 새 파일 `stdict_loanword_phrases.tsv`에 lexicon 행으로 넣었다. 악센트가 있는 키와 없는 키를 함께 넣는다. 여러 낱말 이름은 lexicon 행만 구절로 맞추기 때문이다. 표제어가 이름 일부만 읽는 12개(Siddhārtha Gautama 싯다르타)는 뺐다.
  - **라이선스:** 두 파일 모두 CC BY-SA 2.0 KR이고, 같은 폴더의 `STDICT-LICENSE.txt`를 따른다(2026-10-04 소유자 결정).
- **프로젝트 사전:** 사전에 없는 자주 쓰는 낱말 10개를 `lexicons/ko-KR/accented-additions-v27.jsonl`에 넣었다(Pokémon 포켓몬, Beyoncé 비욘세, Uber 우버, Citroën 시트로엥, Chloé 클로에, Zoë 조이, jalapeño 할라페뇨, façade 파사드, piñata 피냐타, naïve 나이브).

## 5. 사전에 없는 악센트 낱말의 추측

사전에 없을 때는 버리던 악센트를 추측에 쓴다(`src/pronunciation/foreign.c`, `accent_cues`).

| 악센트 | 쓰는 방식 | 예 |
|---|---|---|
| 끝의 é | 소리 냄(묵음 e가 아님) | Doré 도 → 도레이 |
| ï, ë | 앞 모음과 끊어 읽음 | Saïd 사이드, Boë 보이 |
| ñ | ny | Peñarol 페냐롤 |
| ç | s | Gonçalves 곤샐브스 |

- ü·ö·ã는 영어 규칙으로 바꾸면 더 나빠져서(München 모온첸) 그대로 뗀다. 베트남어 글자가 있는 낱말(phở)은 전처럼 뗀다.
- 악센트를 뗀 철자에 사전·외래어·발음 사전 읽기가 있으면 그것이 먼저다.
- **한계:** 규칙은 가까운 읽기까지만 낸다. 굳어진 표기는 사전으로 넣는다.
