# 한국어 의류·속옷 사이즈 읽기 (v0.24)

한국어 문장 속 `3XL`, `XL`, `75AA` 같은 사이즈 표기를 speech 출력에서 읽는다. 이전에는 원문
그대로 TTS에 넘어갔다(사이즈 분류 214문장).

## 1. 참조 실측 (AI Hub 159)

| 표기 | 건수 | 참조 읽기 |
|---|---:|---|
| `2XL`~`6XL`, `2XS`, `3XS` | 177 | 투 엑스라지, 쓰리 엑스라지, 투 엑스스몰 |
| `XL` 단독 | 43 | 엑스라지 41, 엑스엘 2 (둘 다 프로그램 제목) |
| `XS` 단독 | 13 | 엑스스몰 8, 엑스에스 5 |
| 속옷 `65`~`100` + 컵 (`75A`, `80B`, `75AA`) | 117 | 칠십 오 에이, 팔십 비, 칠십 오 에이 에이 |
| `S`, `M`, `L` 단독 | 85 | 에스, 엠, 엘 (이미 읽던 대로) |

## 2. 규칙

- **적용 범위:** speech 출력이고, 처리 단위 안에 한글이 있을 때만 적용한다. 영어 문장과 text 모드는
  그대로다.
- **배수 사이즈:** 앞뒤에 영문자·숫자가 붙지 않은 `N` + `XL`/`XS`를 읽는다. N은 2~6이다.
  - 배수는 영어 수사(`apparel_size_multiplier`: 투, 쓰리, 포, 파이브, 식스)로, 뒤는 사이즈 단어로 읽는다.
  - `3XL` → 쓰리 엑스라지, `2XS` → 투 엑스스몰
- **단독 사이즈 단어:** `XL`, `XS`, `XXL`, `XXS`, `XXXL`, `XXXS`는 발음 사전
  (`lexicons/ko-KR/apparel-additions.jsonl`)과 `apparel_size` 리소스로 읽는다.
  - `XL를` → 엑스라지를: 조사는 그대로 이어진다.
  - `XXL` → 투 엑스라지. 이전에는 "x x l"이었다.
- **속옷 사이즈:** 선언된 밑둘레(`bra_band`: 65~100, 5 간격)와 컵(`bra_cup`: AA, A~F)이 대상이다.
  - 밑둘레는 값으로, 컵은 글자 이름으로 읽는다.
  - `75AA` → 칠십오 에이에이, `100D` → 백 디
- **바뀌지 않는 것:**
  - 숫자+글자 일반 정책. `20F`, `45A`, `32G`는 계속 원문 보존이다(v0.21 결정).
  - 제품 코드 속 표기(`AB3XL12`)

## 3. 측정

- 한국어 벤치마크(보정 variant): 76.84% → **77.00%**. 새로 맞음 229, 새로 틀림 4.
  - 틀림 4건: `XS`를 "엑스에스"로 읽은 참조 3건과 프로그램 제목 `극한연애 XL` 1건
- 영어 벤치마크 변화는 0이다.
- speech 출력에 영문이 남은 문장: 729 → 497. 사이즈 분류에서는 214 → 15.
- 계약 `tests/evaluation/ko_apparel_size_v24.jsonl` 22건. 결과를 구현 전에 작성했다.
- 기존 계약 1행(`사이즈 XL`)을 바꿨다. 2026-09-22 Z/번호 기호 변경의 회귀 가드로 당시 출력을 고정해 둔
  행이다. 이전 값은 notes에 있다.
