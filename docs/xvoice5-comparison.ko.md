# xvoice5 TN 비교 (2026-10-23)

사내 xvoice5 TN(`PowerTTS-S Ver 4.9.5.1.3-TN1.14.5 Korean`, tts_xvoice-text2label @ fe11890b)과 TTF를 소유자 오픈셋 v3 한국어 2,000문장(dev 1,400 / test 600, 2,333스팬)으로 비교했다. 채점은 두 엔진 모두 v3 채점기 그대로다. xvoice5 패키지와 출력은 VM 로컬(`~/xvoice5-tn`, `benchmark/generated/user-tn-eval-v3/out/`)에만 있다.

## 점수 (스팬)

| 구성 | dev | test | test 문장 |
|---|---|---|---|
| TTF 수정 전 (main 141747b) | 92.2% | 93.7% | 92.7% |
| TTF 수정 후 | 93.1% | 94.3% | 93.3% |
| xvoice5 공식 | 74.8% | 75.5% | 71.7% |
| xvoice5 발음 표기 조정 | 80.4% | 80.8% | 77.7% |
| xvoice5 + 우리 사전 | 74.7% | 75.0% | 71.0% |
| xvoice5 + 우리 사전, 조정 | 80.0% | 80.0% | 76.7% |

- **발음 표기 조정:** xvoice5는 자기 G2P 입력용으로 소리 나는 대로 적는다. 제곰→제곱, 키로→킬로, 미리미터→밀리미터, 떠블류→더블유, 딸라→달러를 표준 철자로 바꿔 채점했다.
- **사전:** v3 스팬 속 영어 낱말 70개 중 TTF가 주소 낱말 사전으로 읽는 22개를 xvoice5 사용자 사전(cp949)으로 넣었다. 점수는 오르지 않았다(토큰 분리가 바뀌어 COVID-19 → 코비드마이너스십구, techmall.com → 테크몰 컴). TTF의 우위는 사전 덕이 아니다.
- **스팬 대조(TTF 수정 후 대 xvoice5 조정, 2,333스팬):** 둘 다 맞음 1,841, TTF만 339, xvoice5만 37, 둘 다 틀림 116.
- **범주(dev):** TTF가 18개 중 12개에서 앞서고(날짜, 코드, 수식, 분수·비율, 통화, 단위가 20%p 이상), 3개는 같고, 범위(−13.8%p)·전자주소·기수에서 뒤진다.
- **주의:** v3는 우리 소유자 세트와 같은 지시문으로 만들어 TTF에 홈그라운드 효과가 있다.

## 고친 것 (xvoice5가 맞힌 우리 버그)

- 24:00 이십사 시, 24:00:00 이십사 시. 2026-10-02 결정(시각처럼 보이는 콜론은 보존)을 v3 근거로 바꿨다. 계약 `ko_jev_leaks2_v24`, `ko_written_fallback_v24` 1건씩 Was.
- PM2.5 피엠 이 점 오: 대문자 1-4자 뒤 소수는 글자 이름 + 한국어 수. PM10은 그대로 모델명.
- 2:2:1 이 대 이 대 일: 시각이 될 수 없는(두 자리 59 이하가 아닌 항이 있는) 세 항 이상은 비율.
- 세 규칙 모두 한국어 요청이나 한글이 있는 문장에서만(영어 요청의 24:00, 12:30:60은 그대로). 계약 `ko_v3_fixes_v113`(6).
