# 한국어 단위 표기 누출 (v0.24)

speech 출력에 원문 그대로 남던 단위 표기를 읽는다. 규칙은 AI Hub 159 참조의 실측을 따른다.

## 1. 숫자 뒤 단위

| 표기 | 참조 | 읽기 |
|---|---|---|
| 금 순도 `14K` `18K` `24K` (`k` 포함) | 케이 32/32 | 십팔 케이 (`letter_unit K/k karat`) |
| `4K` `8K` | 포케이 46/46 | 포케이, 에잇케이 (사전 항목) |
| `2G`~`5G` (대문자) | 파이브지 45:1, 투지·쓰리지·포지 | 사전 항목. `5g` 오지 → 파이브지, `3g`·`4g` 삼지·사지 → 쓰리지·포지 |
| 용량 `8`~`2048` + `G` | 기가 | 삼십이 기가 (`letter_unit_values`로 값 제한, `470G 모델`은 제외) |
| `m/s` `km/s` | 초속 9/9 | 초속 삼백사십 미터 |
| `W/kg` | 와트퍼킬로그램 2/2 | 와트 퍼 킬로그램 |
| `Kcal` `KCAL` `kal` | 킬로칼로리 17/17 | 공통 단위 별칭 |
| `kw` `KW` | 킬로와트 8/9 | 공통 단위 별칭 |
| `GWh` `MWh` | 기가와트시 | 새 단위 |
| `cc` | 씨씨 147:3 | 공통 단위로 옮겨 범위·나열도 읽음. 읽기를 시시 → 씨씨로 바꿈 |
| `4만 2000km인` | 사만 이천 킬로미터 | 규모 단어가 섞인 수 뒤 단위는 speech에서 어미가 붙어도 읽음 |

참조가 갈리거나 대부분 단위가 아닌 것은 넣지 않았다.

| 표기 | 참조 |
|---|---|
| 대문자 `M` | 엠 35 : 미터 5 |
| `V` | 2 : 2 |
| `C` | 씨 26 : 컵 4 |
| `T` | 티 18 |

## 2. 숫자 없는 단위 약어

숫자 없이 쓴 단위 약어는 **대소문자로 갈린다.**

| 표기 | 참조 |
|---|---|
| 대문자 `KB` | 글자 읽기 219/219 |
| 대문자 `ML` `KG` `KM` `MG` `MM` `CM` | 글자 읽기 100% |
| 소문자 `kb` | 글자 읽기 4/4 |
| 소문자 `km` `kg` `cm` `ml` | 단위 100% (`kg당`, `몇 ml`, `60여 cm`) |

그래서 이렇게 읽는다.

- 발음 사전 항목에 `lexicon_case ko-KR en-US:<항목> lower`를 달면, 대문자로만 쓴 표기에는 그 항목을 쓰지 않는다.
  - `KB국민은행` → 케이비국민은행, `KG이니시스` → 케이지이니시스, `MG손해보험` → 엠지손해보험
  - 이전에는 킬로바이트국민은행, 킬로그램이니시스, 밀리그램손해보험이었다.
- `kb`는 단위 사전에서 뺐다.
- 반대로 `upper`는 소문자가 섞인 표기에 그 항목을 쓰지 않는다. `5G` 계열에 쓴다(`생강 2g` → 이 그램).
