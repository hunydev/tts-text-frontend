# 콘텐츠 제작 발음 사전: 근거와 검토 대기 항목

## 추가 범위

`lexicons/ko-KR/content-additions.jsonl`은 영상 편집, 디자인, 오디오 작업에서
사용할 **73개 신규 표제어**를 담는다. 0.9.0의 기존 215개 발음 키와 중복되는
표제어는 추가하지 않았다. 수량을 늘리기 위한 대소문자 별칭이나 영문 복수형
복제도 없다. 모든 레코드는 `category: content`, `source_lang: en-US`,
`target_lang: ko-KR`이다.

| 검토 상태 | 개수 | 이 상태가 의미하는 것 |
| --- | ---: | --- |
| `source-checked` | 64 | 연결한 공식 한국어 문서에서 선택한 한글 표기를 확인함 |
| `pending` | 9 | 발음 편집자 또는 서비스 운영자의 읽기 선택이 추가로 필요함 |

`source-checked`는 **한국어 표기가 출처에 있다는 상태**다. 독립 전문가 승인,
모든 문맥의 발음 정확성, 국립국어원 표준 표기 판정을 뜻하지 않는다. 이 자료는
개발 에이전트가 2026-09-16에 확인했다. 음성 합성·청취 평가는 수행하지 않았다.

## 출처와 편집 원칙

출처 원장은 [`lexicons/sources/content.json`](../lexicons/sources/content.json)이다.
각 레코드의 `evidence`가 원장의 `id`를 가리킨다. URL, 자료 종류, 확인 날짜와
확인 범위를 기록한다. 웹 문서나 외부 발음 사전을 일괄 복제하지 않았으며,
짧은 제품명과 개별 용어의 표기를 확인하는 데만 사용했다.

- 제품 이름은 공급자의 한국어 표기를 우선 확인했다. 예를 들어 Adobe의
  [제품 업데이트](https://blog.adobe.com/ko/publish/2025/06/27/create-ideate-faster-with-new-creative-cloud-firefly-innovations)는
  Lightroom, Illustrator 및 Camera Raw의 한글 명칭을 제시한다.
- 편집 용어는 [Premiere 공식 한국어 인터페이스 문서](https://helpx.adobe.com/kr/premiere/desktop/get-started/keyboard-shortcuts/default-keyboard-shortcuts.html),
  오디오 용어는 [Apple Logic Pro 공식 한국어 설명서](https://support.apple.com/ko-kr/guide/logicpro/lgcp569d595f/mac)의
  **음역된 용어**를 대조했다. `clip → 영상 조각` 같은 번역은 넣지 않았다.
- 여러 단어인 제품명은 그대로 하나의 표제어로 기록했다. `Media Encoder`,
  `Character Animator`, `YouTube Shorts` 등이 해당한다. 영어 문맥에서는 원문
  보존이 우선이며, 한글 발음 사전이 존재한다고 항상 한글로 바꾸는 것이 아니다.
- 표제어의 대소문자는 원어의 통상 표기를 보존했다. 조회 시의 대소문자·공백
  정규화와 원장의 표시용 철자는 구분한다.
- 일반 영어 단어와 같은 이름을 가진 제품도 있다. 현재 시스템은 뜻별 동음이의
  사전이 아니므로 특정 브랜드 의미만을 추론했다고 설명하면 안 된다.

공식 출처의 한국어 표기 역시 서로 다를 수 있다. 서로 다른 표기를 발견했을 때
어느 한쪽을 숨기고 검토 완료로 표시하지 않는다.

## 검토 대기 9개

| 표제어 | 현재 제안 | 검토가 필요한 이유 |
| --- | --- | --- |
| Acrobat | 아크로뱃 | Adobe 공식 문서 간에 `아크로뱃`과 `애크로뱃`이 공존함 |
| MIDI | 미디 | 이 원장에서는 공식 한국어 발음 근거를 확인하지 못함 |
| MP3 | 엠피쓰리 | 문자명과 숫자의 영어식 읽기 선택 |
| MP4 | 엠피포 | 문자명과 숫자의 영어식 읽기 선택 |
| WAV | 웨이브 | 단어식 읽기를 선택한 임시 정책 |
| PNG | 피엔지 | 문자명 읽기 선택; 단어식 읽기와의 선호 확인 필요 |
| JPEG | 제이펙 | 단어식 읽기와 받침 표기에 대한 편집 확인 필요 |
| SVG | 에스브이지 | 문자명 읽기 선택 |
| HDR | 에이치디알 | 문자명 읽기 선택 |

Acrobat의 두 근거는 [Adobe 제품 블로그](https://blog.adobe.com/ko/publish/2026/03/12/image-editing-just-got-smarter-with-ai-photoshop-firefly)와
[Adobe PDF 편집 안내](https://www.adobe.com/kr/acrobat/roc/blog/how-to-edit-indesign-pdf.html)다.
나머지 8개는 자체 작성한 음역 후보이다. 형식 이름이 공식 문서에 영문으로
등장한다는 사실만으로 그 한글 발음을 검증했다고 표시하지 않는다.

검토 대기 레코드를 사용하는 경우, 결과가 사전과 일치하는지 확인하는 테스트와
읽기 선택 자체를 승인하는 절차를 구분한다. 현재 후보가 서비스에 맞지 않으면
고객·사용자 사전에서 덮어쓸 수 있다. 코드, URL, 파일 경로처럼 보호된 문맥은
별도의 원문 보존 정책을 따른다.

## 기존 사전에서 함께 고쳐야 할 선택값

이 절은 기존 항목의 수정 근거다. 신규 73개 항목에 중복으로 넣지 않는다.

| 기존 키 | 0.9.0 읽기 | 권장 변경 | 근거의 범위 |
| --- | --- | --- | --- |
| `aftereffects` | 애프터이펙츠 | 애프터 이펙트 | 공급자의 제품 한글명으로 통일 |
| `after effects` | 애프터 이펙츠 | 애프터 이펙트 | 동일 제품명의 공백 입력 변형 |
| `postgresql` | 포스트그레에스큐엘 | 포스트그레스큐엘 | 공식 원어 발음 설명을 토대로 한 한국어 음역 후보 |

Adobe의 [공식 제품 안내](https://blog.adobe.com/ko/publish/2021/10/27/cruise-through-creative-work-latest-release-creative-cloud-video-apps)는
After Effects의 한국어 제품명을 직접 제시한다. 붙여 쓴 입력 키도 같은 제품명으로
출력하자는 것은 프로젝트의 별칭 정책이다.

PostgreSQL의 [공식 FAQ](https://www.postgresql.org/about/press/faq/)는 원어 발음을
`post-GRES-que-ell`로 안내한다. 따라서 기존의 `...그레에스...`라는 분절은
재검토 대상이다. **권장 한국어 후보 자체가 공식 한국어 표기는 아니다.**
이를 채택해도 한국어 음역의 검토 상태는 `pending`으로 두고, 원어 발음 근거와
프로젝트의 한국어 렌더링 선택을 함께 기록해야 한다. FAQ에 링크된 음성은
합성음 평가나 정답 판정에 사용하지 않았다.

기존 회귀 코퍼스의 기대값도 실제 변경한 키에 맞게 수정하되, 이전 값·새 값·이유를
수정 이력에 남긴다. 엔진이 새 값을 출력한다는 이유만으로 표기를 승인하지 않는다.

## 사람이 검토하고 수정하는 방법

1. 실제 콘텐츠 원문에서 틀린 단어와 앞뒤 문장을 함께 기록한다. 제목, 영어 문장,
   코드 등 보존해야 할 문맥인지 먼저 확인한다.
2. 원장 JSONL에서 `term`을 찾아 `pronunciation`, `review_status`, `evidence`,
   `notes`를 검토한다. 한국어 뜻을 번역값으로 넣지 않는다.
3. 공식 한국어 제품명이 확인되면 출처 원장에 페이지와 확인 범위를 기록한다.
   원어 발음만 확인했다면 한국어 음역까지 자동으로 검토 완료 처리하지 않는다.
4. 팀의 발음 편집자가 선택한 경우 검토 주체·날짜·이유를 추가한다. 에이전트가
   작성했다는 이유만으로 사람이 승인했다고 기록하지 않는다.
5. 사전 빌드 및 검사 후 한국어 조사와 붙인 입력, 영어 원문 보존, 청크 스트리밍,
   상위 계층 덮어쓰기까지 확인한다. 결과 문자열뿐 아니라 `inspect`에서 사전
   조회가 일어났는지도 확인한다.

기존 런타임 TSV와 고객별 덮어쓰기 방법은
[리소스 수정 가이드](resource-editing-guide.ko.md)를 참고한다. 생성된 런타임
파일을 직접 수정하면 원장에서 다시 빌드할 때 사라질 수 있으므로, 시스템 사전의
영구 수정은 원장에 반영한다.

## 텍스트 검증용 수작업 예문

다음 기대 문자열은 엔진 출력에서 생성하지 않고, 위 읽기 선택과 한국어 조사
결합을 기준으로 작성했다. 별도의 인간 전문가 검수 완료 데이터나 실사용 분포의
정확도 평가 자료가 아니다. 선택한 표기가 바뀌면 근거와 함께 다시 검토한다.

| 입력 | 기대 출력 |
| --- | --- |
| `Illustrator로 로고를 만듭니다.` | `일러스트레이터로 로고를 만듭니다.` |
| `Lightroom에서 사진을 보정합니다.` | `라이트룸에서 사진을 보정합니다.` |
| `Media Encoder로 영상을 내보냅니다.` | `미디어 인코더로 영상을 내보냅니다.` |
| `Character Animator로 캐릭터를 움직입니다.` | `캐릭터 애니메이터로 캐릭터를 움직입니다.` |
| `YouTube Shorts에 영상을 올립니다.` | `유튜브 쇼츠에 영상을 올립니다.` |
| `green screen으로 배경을 촬영합니다.` | `그린 스크린으로 배경을 촬영합니다.` |
| `sequence에 clip을 추가합니다.` | `시퀀스에 클립을 추가합니다.` |
| `clip의 audio를 확인합니다.` | `클립의 오디오를 확인합니다.` |
| `overlay를 추가합니다.` | `오버레이를 추가합니다.` |
| `compressor로 소리의 크기를 조절합니다.` | `컴프레서로 소리의 크기를 조절합니다.` |
| `template의 layout을 바꿉니다.` | `템플릿의 레이아웃을 바꿉니다.` |
| `crossfade로 두 소리를 연결합니다.` | `크로스페이드로 두 소리를 연결합니다.` |

아래 영어 문장은 사전 항목이 있어도 **각각 입력과 같은 문자열**이어야 한다.

- `Please add the clip to the sequence.`
- `Use Lightroom to edit the photo.`
- `The audio track is ready.`
- `Open the Media Encoder project.`
- `Please upload the video to YouTube Shorts.`
- `The compressor and limiter are enabled.`

## 다음 수집 우선순위

콘텐츠 제작 도구의 기능명·파일 형식·오디오 용어 중 실제 실패 빈도가 높은 항목을
먼저 수집한다. 새로운 단어 수와 실제 입력에서의 미등록 비율 감소를 함께 본다.
서비스별 약어 선호, 사람·채널 이름, 최신 제품명은 고객 사전에서 관리할 수 있게
유지한다. 단어 사전의 확대만으로 문맥 판정, 미등록 단어 G2P, 조사 자동 교정까지
완성되는 것은 아니므로 각각 별도 품질 지표와 검토 자료가 필요하다.


README 실제 실행 점검에서 `Premiere Pro`가 단어별로 나뉘어 `Pro`의 fallback에
의존하는 누락을 발견했다. Adobe 공식 문서의 `프리미어 프로` 표기를 근거로
전체 제품명 항목을 추가했고, 두 제품명을 연결한 한국어 문장과 영어 원문 보존
사례를 `lexicon_v10.jsonl`에 추가했다. 기존 `Adobe Premiere Pro` 키는 유지한다.
