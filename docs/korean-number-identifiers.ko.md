# 숫자 번호: 하이픈과 긴 숫자 (v0.24)

speech 출력에서 번호로 쓰인 숫자를 금액이나 범위처럼 읽던 문제를 고친다(2026-10-01 결정).

- 하이픈으로 이은 숫자는 계좌번호·전화번호처럼 번호로 읽는다.
- 쉼표도 단위도 없이 이어진 긴 숫자는 한 자리씩 읽는다.

## 1. 하이픈으로 이은 두 숫자 묶음

**기본은 번호다.** 한 자리씩 읽고 하이픈은 `다시`로 읽는다. 전화번호 인식기가 이미 잡은 번호는 그대로 둔다(`1588-0000` 일오팔팔 공공공공).

| 입력 | 이전 | 지금 |
|---|---|---|
| `27022-8080 통장` | 이만 칠천이십이에서 팔천팔십 통장 | 이칠공이이 다시 팔공팔공 통장 |
| `970017-3461793번` | 구십칠만 십칠에서 삼백사십육만… 번 | 구칠공공일칠 다시 삼사육일칠구삼번 |
| `30-520869511 포장` | 서른에서 오억 이천팔십육만… 포장 | 삼공 다시 오이공팔육구오일일 포장 |
| `2020-1234호` | 이천이십에서 천이백삼십사 호 | 이공이공 다시 일이삼사호 |
| `12-34를` | 십이에서 삼십사를 | 일이 다시 삼사를 |

**범위(`에서`)는 후순위다.** 아래 경우에만 범위로 읽는다.

1. 앞 수가 뒤 수보다 작고, 뒤 묶음 바로 다음에 단위나 수 세는 말이 온다. 묶음 길이는 단위·통화·퍼센트면 5자리, 수 세는 말이면 4자리까지다. 숫자에 바로 붙은 한글이 조사가 아니면 수 세는 말로 본다(`3-5세`, `2-3회`, `5-10위안`).
   - 예: `3-4개` 서너 개, `10-20%` 십에서 이십 퍼센트, `1000-2000명`, `7-10일간`
2. 번호에 붙는 말(`digit_label_counter`: 번, 호, 번지, 동, 차)이 오면 한두 자리일 때만 범위로 읽는다.
   - 예: `4-5번 정도` 사오 번, `1234-5678번`은 번호
3. 범위 신호어(`digit_range_cue`: 사이)가 뒤에 온다.
   - 예: `가격은 12000-15000 사이`
4. 뒤에 큰 수 단위(만, 억, 십, 백, 천, 조)가 온다. 이때는 큰 수 범위 문법이 읽는다.
   - 예: `100-200만 원` 백에서 이백만 원
5. 네 자리 연도 두 개다(1000~2999, 차이 100 이하).
   - 예: `2019-2020 시즌` 이천십구에서 이천이십 시즌
6. 뒤 묶음이 줄인 표기이고 수 세는 말이 붙는다.
   - 예: `24-5개월` 이십사에서 오 개월

**경기 점수는 `대`로 읽는다.** 문장에 경기 신호어가 있고 숫자 쌍이 짧으면(각 3자리 이하, 앞자리 0 없음, 단위 없음) 점수로 읽는다. 신호어는 `score_cue` 낱말의 앞부분으로 찾는다(승리, 졌, 비겼, 무승부, 동점, 꺾, 뒤집, 앞서, 경기, 세트, 골 등). 읽기에 쓰는 말은 `policy score_separator 대`로 바꿀 수 있다.

| 입력 | 지금 |
|---|---|
| `25-18로 졌습니다` | 이십오 대 십팔로 졌습니다 |
| `2-0 승리로 끝이 났다` | 이 대 영 승리로 끝이 났다 |
| `102-98로 이겼다` | 백이 대 구십팔로 이겼다 |
| `문의 3-5` (신호어 없음) | 문의 삼 다시 오 |

이 규칙이 없을 때 /jev-eval의 스포츠 인정률이 59.5%에서 53.5%로 떨어져서 추가했다. 그 전의 범위 읽기(이십오에서 십팔)도 틀린 읽기였다.

**배수 글자로 시작하는 낱말은 배수가 아니다.** `417-00-32154 조회`는 `조회`의 `조`를 배수(조)로 보고 범위 보호 규칙이 원문 그대로 두었다. 이제 배수 뒤가 조사, 수량 꼬리말, 숫자 접미사, 다른 배수일 때만 배수로 본다(`1-2조 원`, `1-2조원을`은 그대로 범위). 번호 뒤에 붙은 한글(`417-00-32154번`)은 번호를 읽은 뒤 그대로 붙인다.

| 입력 | 이전 | 지금 |
|---|---|---|
| `사업자 번호 417-00-32154번 조회` | 원문 그대로 | 사업자 번호 사일칠 다시 공공 다시 삼이일오사번 조회 |
| `417-00-32154 조회` | 원문 그대로 | 사일칠 다시 공공 다시 삼이일오사 조회 |

**범위로 읽게 하려면 `~`를 쓴다**(`12~34`). 수식은 `4-3{@math}`(사 빼기 삼), 경기 신호어가 없는 점수는 `10-10{@score}`(십 대 십), 주소의 번지는 `[[역삼동 123-45]]{@address}`(백이십삼 다시 사십오)로 지정한다. 이 규칙은 한국어 문맥에서만 동작하며 영어 문장의 `pages 3-5`는 그대로다.

## 2. 다섯 자리 이상 숫자

쉼표 묶음이 없고 뒤에 단위나 수 세는 말이 없는 **다섯 자리 이상** 숫자는 번호로 보고 한 자리씩 읽는다(2026-10-02 결정, 이전에는 9자리부터). 네 자리까지는 금액처럼 읽는다(`1234` 천이백삼십사). 금액으로 읽게 하려면 `{@sino}`·`{@cardinal}` 제어를 쓴다(`15000{@sino}` 만 오천).

읽을 때는 3~5자리씩 끊는다. 5, 4, 3 가운데 나누어떨어지는 가장 큰 크기로 고르게 나누고(5자리 그대로, 6자리 3-3, 8자리 4-4, 9자리 3-3-3, 10자리 5-5, 12자리 4-4-4), 나누어떨어지지 않으면 5자리를 먼저 끊고 나머지를 다시 나눈다. 다만 세 자리보다 짧은 묶음은 만들지 않으므로 7자리는 4-3이다(11자리 5-3-3, 13자리 5-4-4). 직접 끊으려면 `{@digits:N}`을 쓴다(`01012341234{@digits:344}`).

| 입력 | 이전 | 지금 |
|---|---|---|
| `874456932101이` | 팔천칠백사십사억 오천육백구십삼만 이천백일이 | 팔칠사사 오육구삼 이일공일이 |
| `326253620012더라` | 삼천이백육십이억… 십이더라 | 삼이육이 오삼육이 공공일이더라 |
| `2017345678번` | 이십억 천칠백삼십사만… 번 | 이공일칠삼 사오육칠팔번 |
| `12345678901` | 백이십삼억… | 일이삼사오 육칠팔 구공일 |

**금액이나 수량은 그대로다.**

| 입력 | 읽기 |
|---|---|
| `1,234,567,890원` (쉼표) | 십이억 삼천사백오십육만 칠천팔백구십 원 |
| `123456789012원` (통화) | 천이백삼십사억… 원 |
| `1234567890명` (수량) | 십이억… 명 |
| `9800000000달러` | 구십팔억 달러 |

번호에 붙는 말(번, 호 등)은 단위로 치지 않는다. **억·조로 읽게 하려면 기존 제어 구문 `{@sino}`를 쓴다**(annotated 입력).

```text
874456932101{@sino}이 오늘  →  팔천칠백사십사억 오천육백구십삼만 이천백일이 오늘
```

## 3. 설정과 구현

- **리소스:** `resources/languages/ko-KR/rules/numeric.tsv`
  - `policy hyphen_digits identifier|range`: `range`면 이전 읽기로 돌아간다. 도메인이 `range_mode digits`를 정하면(금융 예제 정책, `123-456` 일이삼 사오육) 그 읽기를 따른다.
  - `policy long_digit_identifier_min 9`: `0`이면 끈다. 7~16 사이로 정할 수 있다.
  - 단어 목록: `digit_label_counter`, `digit_range_scale`, `digit_range_cue`
- **분류기:** `languages/ko-KR/identifiers.c`의 `ttf_ko_classify_digit_identifier`. speech 출력에서만 동작한다.
- **엔진 공통 코드:** `src/core/normalize.c`. 우선순위 100 이상인 언어 팩 규칙은 공통 숫자 문법이 뒤의 수 세는 말까지 더 길게 잡았어도 이긴다(`27022-8080 통장`의 통, `2019-2020 시즌`의 시). 다만 전화번호 인식 결과와, 공통 문법이 이미 번호로 판정한 결과는 대체하지 않는다. 공통 문법이 번호로 판정한 범위 끝에 붙은 한글은 번호만 읽고 그대로 남긴다(`identifier_tail`).
- **계약:** `tests/evaluation/ko_number_identifiers_v24.jsonl` 32건(점수 5건, 배수 글자 낱말 3건 포함). 구현 전에 작성했다.
- **바뀐 기존 계약:** 정책 변경으로 기대값이 바뀐 기존 계약 12건은 notes에 이전 값을 남겼다.
  - 단위 없는 짧은 쌍(`5-3`, `문의 12-34`)은 이제 번호로 읽는다. `경기는 3-2로 끝났다`는 점수로 삼 대 이로 읽는다.
  - 큰 수 띄어쓰기 계약 5건은 금액 읽기를 계속 시험하도록 입력에 `명`을 붙였다(`100000001명` 일억 일 명).

## 4. 측정

- 한국어 벤치마크(보정 variant): 76.97% → **78.59%**. 새로 맞음 1,873문장, 새로 틀림 1문장(참조가 `63-40번지`를 육십삼에서 사십 번지로 읽음). 이 가운데 점수 규칙의 몫은 236문장이다.
- 남은 과제: `3-1절`, `6-25 전쟁`은 이제 삼 다시 일절, 육 다시 이오로 읽힌다. 이전의 "삼에서 일절"보다는 낫지만, 관용 읽기(삼일절, 육이오)는 사전 항목으로 다룰 일이다. 콜론은 시간 문법을 따르고, 시간으로 읽을 수 없는 쌍만 점수·비율로 `대`를 넣어 읽는다(2026-10-02: `3:2로 승리` 삼 대 이로, `1:1 질문` 일 대 일). `24:00`처럼 0으로 시작하는 두 자리 묶음은 시간처럼 보여 그대로 둔다.

## 5. 모델 번호·야구 카운트·이름 (2026-10-01)

**제품 이름 뒤 모델 번호는 10까지 영어, 11부터 한자어로 읽는다.** 글자 뒤 번호는 버스·구역·사이즈(`N10번 버스` 엔십번, `B10 구역` 비십)일 때가 많아 한 자리만 영어로 읽는다.

| 입력 | 읽기 | 규칙 |
|---|---|---|
| `K5`, `PS5` | 케이파이브, 피에스파이브 | 글자 뒤 한 자리 |
| `GV70`, `G80`, `S10` | 지브이칠십, 지팔십, 에스십 | 글자 뒤 두 자리 |
| `아이폰6 대란`, `갤럭시노트10` | 아이폰식스 대란, 갤럭시노트텐 | 제품 이름(`model_name`) 뒤 10 이하 |
| `아이폰11`, `아이폰 14` | 아이폰십일, 아이폰 십사 | 제품 이름 뒤 11 이상 |
| `아이폰 2대를` | 아이폰 두 대를 | 수 세는 말이 붙으면 수량 |
| `ABC123`, `ABC127` | 에이비씨원투스리, 에이비씨원투세븐 | 대문자 둘 이상 뒤 세 자리 이상은 코드: 한 자리씩 |

- 대문자 둘 이상 뒤 숫자가 한두 자리로 끝나면(`GV70`) 모델 번호로 읽는다. 전에는 숫자를 한 자리씩 영어 발음 변환으로 읽어 `GV70`이 지브이세번지로가 됐다. 코드의 영어 숫자도 이제 사전 낱말(세븐, 제로)을 쓴다.
- 영어 숫자 말은 사전의 `en-US:one`~`en-US:ten` 항목을 쓴다(3 스리, 8 에이트). 제품 이름 목록은 `resources/languages/ko-KR/rules/numeric.tsv`의 `model_name`이다.
- **야구 카운트:** `counter 아웃 english`, `counter 스트라이크 english`. `2아웃` 투 아웃, `1아웃 2스트라이크` 원 아웃 투 스트라이크.
- **사이즈:** 소문자 `2xl`, `3xl`도 대문자처럼 읽는다(투 엑스라지).
- **이름:** `2NE1` 투애니원, `2TV` 이티비, `4D` 포디. 그 밖의 숫자+글자 표기(`20F`, `5A`, `470G`)는 뜻이 갈려서 기존대로 원문을 유지한다(`unreadable=read`이면 읽는다).
- 계약: `tests/evaluation/ko_alnum_models_v24.jsonl` 23건. 구현 전에 작성했다.

## 6. 번호 이름 뒤의 숫자·조사 만 (2026-10-01)

**`…번호`로 끝나는 말 뒤의 숫자는 한 자리씩 읽는다.** 등록된 이름(`identifier_label`)이 아니어도 앞말이 있는 `…번호`(예매번호, 주민번호, 항공 번호)면 번호로 본다. 전화·폰이 들어간 말(전화번호, 휴대폰번호)은 전화번호 문법을 그대로 따르고, 맨 `번호`만 있거나 숫자가 세 자리 이하이면 바꾸지 않는다(`번호 3번을` 삼 번을). 등록된 이름이 있으면 그것이 먼저다.

| 입력 | 이전 | 지금 |
|---|---|---|
| `예매번호 12578로` | 만 이천오백칠십팔로 | 일이오칠팔로 |
| `주문번호를 4689326으로` (이름 뒤 조사) | 사백육십팔만… | 사육팔구삼이육으로 |
| `예약번호 2021034인` (서술격 조사) | 이백이만 천삼십사인 | 이공이일공삼사인 |
| `항공 번호 63107508번이` | 육천삼백십만 칠천오백팔 번이 | 육삼일공칠오공팔번이 |
| `56478910이 예약번호이며` (이름이 뒤에) | 오천육백사십칠만… | 오육사칠팔구일공이 |

**하이픈 쌍 뒤의 `만`은 묶음이 다섯 자리 이상이면 조사(only)다.** `254412-774521만 있으면`은 이십오억… 범위가 아니라 이오사사일이 다시 칠칠사오이일만, `주민번호 540019-3758929만`은 오사공공일구 다시 삼칠오팔구이구만이다. `100-200만 원`처럼 네 자리 이하는 그대로 배수다.

**번호 이름 뒤 네 자리 이하 + `번`은 대기 번호처럼 센다.** `예약번호 89번`은 팔십구 번, `예약번호 1323번인데`는 천삼백이십삼 번인데다. 비밀번호·암호·인증번호·핀번호·예매번호(`short_code_label`)는 짧아도 한 자리씩 읽는다(`비밀번호 7537번` 칠오삼칠번). AI Hub 159 참조 집계: 비밀번호 한 자리씩 201 / 수 0, 예매번호 13 / 0, 예약번호 83 / 78(수로 둠). 다섯 자리 이상은 이름과 상관없이 번호다(`항공 번호 63107508번이`).

- 계약: `tests/evaluation/ko_number_labels_v24.jsonl` 16건. 12건은 구현 전에, 대기 번호·비밀번호 4건은 벤치마크 확인 뒤 작성했다.

## 7. 숫자로 시작하는 코드 (2026-10-02)

## 8. 짧은 표기·나열·사이즈 (2026-10-02)

- 숫자로 시작하는 짧은 표기는 단서가 있을 때만 읽는다. 뒤에 `번`이 붙으면 노선 번호(`38A번` 삼십팔에이번, `31B번 버스` 삼십일비번 버스), 앞에 `…번호`·`…코드`가 있으면 코드(`제품번호 6456A` 육사오육 에이, `제품코드 4047D` 사공사칠 디)다. 단서가 없는 `20F`, `5A`는 그대로 둔다.
- 쉼표로 이은 두 자리 이하 숫자는 나열로 하나씩 읽는다(`1,2라인` 일, 이라인). 뒤에 수 세는 말이 오면(`3,4개`, `1,2층`) 바꾸지 않는다.
- 전화번호 뒤 한글 수 세는 말은 그 낱말이 끝날 때만 본다. `010-1234-5678 개인 폰`의 `개인`은 `개`+`인`이 아니다.
- 사이즈 배수에 7·8·9를 더했다(`8XL` 에이트 엑스라지). `3DS` 쓰리디에스, `8D` 에이트디는 사전 항목이다.
