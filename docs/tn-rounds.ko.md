# TN 개선 회차 기록

회차마다 약점 영역 2–3개를 고르고, 하위 에이전트가 쓴 150줄 이상의 `{표기|읽기/대안}` 평가셋으로 잰다.
처음 측정은 코드를 커밋으로 고정한 뒤에 하고, 수정은 일반 규칙과 어휘집으로만 한다.
점수는 문장 정확도이며 세 가지 설정으로 잰다: 기본, CMU(영어 발음 사전), localize+CMU.
2회차부터는 같은 셋을 main 빌드로도 재서 브랜치와 비교한다.

회차를 닫는 조건: 한국어 릴리스 벤치마크(`korean_quick.py`) 순손실 0, 소유자 평가셋 출력에 의도하지 않은 변화 없음, quick CI_EXIT=0.

검토에서 셋을 넓히는 경우: 엔진이 이미 따르는 소유자 결정(# 샵, C 씨, 조사는 적힌 대로)이나 둘 다 맞는 읽기만 대안으로 더한다. 넓힌 셋으로 main과 브랜치를 다시 재서 같은 기준으로 비교한다.

## 2회차

- 셋: `~/arw/rounds/r2.jsonl` (원본 `r2.orig.jsonl`). 기준 코드는 브랜치 5f85287이고, 같은 셋의 main 점수와 처음 측정은 같았다.
- 넓힌 것: 해시태그 `#`의 샵 읽기(소유자 결정 2026-09-22), `_` 언더스코어와 `.` 닷, `Z` 제트, `±0.5°C`의 섭씨, 동그라미 숫자를 숫자 그대로(`③` 삼), ▲▼의 상승/증가·하락/감소, 따옴표 속 `'22'`의 이십이.

수정:

- 앞에 붙은 기호를 숫자 둘레에서 읽는다(`number_mark`): `▲1.2%` 일 점 이 퍼센트 상승, `▼0.3%p` 영 점 삼 퍼센트포인트 하락, `≥60점` 육십 점 이상, `≤100ml` 백 밀리리터 이하, `~10분` 약 십 분, `≒1,380원` 약 천삼백팔십 원. 기호는 띄어 쓰거나 문장 첫머리에 있어야 하므로 `37.5도~38도`는 범위 그대로이고 `x ≥ 5`는 관계식 그대로다. 뒤 조사는 마지막 낱말에 맞춘다(`▲8.4%로` … 상승으로).
- 화살표 `→`가 양쪽에 붙고 오른쪽이 숫자이면 범위로 읽는다(`speech_range_numeric`): `3.5%→3.25%` 삼 점 오 퍼센트에서 삼 점 이오 퍼센트, `50,000원→35,000원` 오만 원에서 삼만 오천 원. 전에는 화살표가 출력에 그대로 남았다. 낱말 사이(`가→나`, `서울→부산`)는 기존 계약(final-gate-arrow-drop-between-words)대로 둔다. 소유자 근거가 없어서다.
- `1+1 행사` 원 플러스 원, `2+1이라` 투 플러스 원: 한 자리 덧셈 뒤에 판매 낱말(`promo_cue`: 행사, 이벤트, 상품, 제품, 할인, 증정, 특가, 혜택, 프로모션, 이라)이 올 때만. `1+1은 2다`는 그대로 일 더하기 일.
- 파일 확장자 앞 마침표를 읽는다(`file_extension`): `report_final.pdf` 리포트 언더스코어 파이널 닷 피디에프. 전에는 마침표가 그대로 남아 읽히지 않았다.
- `24/7` 투엔티포 세븐(전에는 칠 분의 이십사). `∞` 무한대는 기존 계약(무한)에 소유자 근거가 없어 넣지 않았다.
- 계약 변경(Was: 기록): `math-v21-neg-plus-event` 2+1 행사 이 더하기 일 → 투 플러스 원(소유자 ko-KR-0223), `electronic-v21-neg-filename` report.txt 리포트.티엑스티 → 리포트 닷 티엑스티(소유자 en-US-0994, th-TH-0991, ar-0994가 파일명 점을 읽음).
- 어휘집 `rounds-ko-v30` 42개: 곡명 낱말과 아티스트(Peaches 피치스, Believer 빌리버, Havana 하바나, Macarena 마카레나, Lil Nas X 릴 나스 엑스, Jay-Z 제이지 등), 서비스와 키 이름(KakaoTalk 카카오톡, WhatsApp 왓츠앱, FaceTime 페이스타임, Ctrl 컨트롤, Alt 알트, Tab 탭), 일반어(final 파이널, sales 세일즈, last 라스트, soul 소울). LinkedIn은 링크트인에서 링크드인으로 고쳤다.

소유자셋 변화: ko-KR-0223 `2+1 행사 상품은` 이 더하기 일 → 투 플러스 원. 참조가 투 플러스 원을 허용하므로 틀리던 문장이 맞게 된 것이다.

벤치마크: `1+1 상품`, `2+1이라고` 등 8문장 개선, 손실 0. 처음 넣은 `~` 규칙은 붙여 쓴 범위(`36.7도~37.1도`)를 약으로 읽어 19문장을 잃었고, 띄어 쓴 기호만 받도록 고쳤다.

남은 과제: 낱말 사이 화살표(`서울→부산`)와 `∞` 무한대(소유자 결정 필요), 악센트 이름(`ROSÉ` 로제, `Édith` 에디트; 어휘집 키가 악센트를 지워 rose, edith와 겹친다), 낙타 표기 해시태그 나누기(`#MondayMotivation`), `NCT 127` 일이칠, `As It Was` 워즈(벤치마크 손실로 was 행을 뺐었다), 숫자만 있는 곡명 뒤 `: 7` 세븐, `@hybe_official` 핸들, `①~③` 범위, 부등식 문장(`2x+1>7`).
