# 미등록 영어 단어 추측 발음 측정 (2026-09-24)

## 측정 대상

한국어 문맥에서 자주 나오지만 발음 사전에 **없는** 영어 단어 28개다. 기대 표기는 일반적인
외래어 표기를 독립적으로 작성했고 사람 검수는 대기 상태다. 이 단어들을 사전에 추가하는 것은
개선으로 세지 않는다 (remaining-work의 PRON-01 조건).

- 측정 세트: `tests/evaluation/oov_guess_v21.jsonl` (28건)
- 회귀 게이트: `tests/evaluation/oov_guess_regression_v21.jsonl` (28건 전부 승격)

## 결과

| 시점 | 정확 일치 |
|---|---|
| 변경 전 | 0 / 28 |
| 1차 (문맥 g2p + coda_r) | 14 / 28 |
| 2차 (구개음·이중모음 꼬리) | 20 / 28 |
| 3차 (받침 조건 + l 겹침 + 연결 r) | 28 / 28 |

## 1차: 문맥 있는 자소 규칙

영어 G2P 프로토타입이 단어 시작(`^`)과 끝(`$`) 문맥, 묵음 표시(`-`)를 지원하게 하고
`ss`, `ce`, `sion`, `age$`, `ing$` 같은 규칙을 데이터로 추가했다. 한국어 매퍼는 모음 뒤 `r`를
외래어 표기 관행대로 지우게 했다 (`phone_mapping ko-KR coda_r drop`).

## 2차: 구개음과 이중모음

- 구개음(`JH CH SH ZH`) 뒤의 삽입 모음은 `으`가 아니라 `이`다 (package 패키지, message 메시지).
- `SH`는 뒤따르는 모음을 구개음화한다 (shopping 쇼핑, session 세션).
- 이중모음의 꼬리 음절이 받침을 가져간다 (point 포인트, design 디자인).

## 3차: 받침 조건, `l` 겹침, 연결 `r`

세 규칙 모두 자원으로 선언하고 매퍼가 조건을 해석한다.

- **어말 파열음의 받침**: `P T K`는 **짧은 모음 뒤에서만** 앞 음절을 닫는다
  (market 마켓, 하지만 update 업데이트·report 리포트). 짧은 모음 목록은
  `phone_vowel_length ko-KR AA|AE|AH|EH|IH|UH short`다. 비음·유음 앞에서도 닫지 않는다
  (partner 파트너).
- **`l` 겹침** (`phone_mapping ko-KR onset_l double`): 모음 뒤의 `l`은 앞 음절의 받침 ㄹ과
  자신의 초성 ㄹ로 두 번 적힌다 (platform 플랫폼, delivery 딜리버리, daily 데일리).
- **연결 `r`** (`phone_mapping ko-KR linking_r link`): `ER` 뒤에 모음이 오면 r는 사라지지 않고
  다음 음절의 초성이 된다 (delivery 딜리버리, battery 배터리). 자음 앞·어말에서 지우는
  `coda_r drop`의 반대쪽 규칙이다.

자소 규칙은 `^con`, `nnel`, `^lice`, `nse$`, `ersi`, `on$`, `ake$`를 추가했다.

## 기대값을 고친 기존 참조 3건

프로토타입의 당시 출력을 그대로 적어 둔 참조였고, 새 출력이 표준 외래어 표기에 더 가깝다.
각 케이스의 `notes`에 변경 사유를 남겼다. 사람 검수는 여전히 대기 상태다.

| 케이스 | 이전 | 이후 |
|---|---|---|
| `handle-v21-neg-no-underscore` (snake) | 스내크 | 스네이크 |
| `foreign-v21-guess-default` / `-text-mode-guess` (daily) | 데이리 | 데일리 |
| `initialism-v21-word-policy-it` (IT, word 정책) | 이트 | 잇 |

## 2차 측정 세트 (자음군·다음절·파생형)

첫 28단어가 2~3음절 명사에 치우쳐 있어, 초성 자음군·4음절 이상·파생형을 채운 30단어를
**규칙 변경 전에** 작성했다(`tests/evaluation/oov_guess_wide_v21.jsonl`). 사전에 이미 있는
단어(stream, cloud, premium)는 제외했다.

| 시점 | 정확 일치 |
|---|---|
| 작성 직후 기준선 | 11 / 30 |
| 매퍼 규칙 | 12 / 30 |
| 자소 규칙 묶음 | 24 / 30 |
| 활음·`ㅖ` 보정 | 28 / 30 |
| 형태소 경계 token | 30 / 30 |

매퍼에 넣은 규칙은 네 가지다.

- 지운 `r`는 앞 모음을 길게 만들어 뒤 파열음이 받침이 되지 못하게 한다 (smart 스마트,
  start 스타트). 같은 어말 `T`라도 market은 마켓이다.
- 어말 성절 자음(`L M N NG`)은 자기 음절 대신 `으` 음절의 받침이 된다 (simple 심플,
  prism 프리즘).
- 활음(`W Y`) 앞의 자음은 받침이 아니라 다음 음절의 초성이다 (security 시큐리티,
  community 커뮤니티).
- 구개음 뒤 `ㅔ`는 `ㅖ`가 된다 (sharing 셰어링).

그리고 g2p 값에 형태소 경계 token `.`을 추가했다. 음소가 아니라 "여기서 음절을 끊으라"는
표시이고, 앞 자음이 받침이 된다. `up+loading`과 `person+al`처럼 음운만으로는 알 수 없는
경계를 데이터가 직접 말한다: `^up` → `AH P .` (업로딩, 어플로딩이 아니라),
`^pers` → `P ER S .` (퍼스널라이즈드). 같은 자리를 음운 규칙으로 일반화하면
application 애플리케이션이 깨진다 — `p`+`l`은 보통 받침이 아니다.

자소 규칙은 `ple$`, `ble$`, `al$`, `bile`, `ong$`, `ory$`, `gy$`, `ted$`, `fied$`, `atio`,
`ized$`, `onal`, `^comm`, `unit`, `secu`, `cate`, `^tech`, `nolo`, `univ`, `^vers`, `shar`,
`^conn`, `veri`, `digi`, `^glo`, `^ena`, `^pers`를 추가하고 `ersi`를 `ER S IH`로 바꿨다
(`^vers`가 version 버전을 계속 맡는다).

## 3차: 과적합 점검 세트 (이웃 단어)

2차에서 추가한 규칙 중 `cate`, `nati`, `^comm` 같은 것은 사실상 단어 하나를 겨냥한다.
그래서 **각 규칙의 이웃 단어** 18개를 다시 규칙 변경 전에 작성했다
(`tests/evaluation/oov_guess_neighbour_v21.jsonl`). 기준선은 9/18이었고, 새 규칙이 실제로
망가뜨린 단어가 그 안에 있었다: cater 카테, person 퍼스언, table 태블.

| 시점 | 정확 일치 |
|---|---|
| 작성 직후 기준선 | 9 / 18 |
| 규칙 일반화 후 | 17 / 18 |

한 단어짜리 규칙을 공유 부분으로 바꿨다.

- `cate` → `ateg`: category는 그대로 두고 cater 케이터, later 레이터가 `ate`/`ater`로 풀린다.
- `^pers`의 경계 token 제거 → `^per`: 자음 앞 `S`는 이미 `으`를 받으므로 경계가 필요 없었고,
  person 퍼슨(`son$` → `S AX N`)과 personal 퍼스널이 같은 규칙으로 나온다.
- `nati` 삭제: nation을 내션으로 만들던 규칙이었다. 지우면 `atio`가 nation 네이션을 맞춘다.
- 새 reduced 모음 `AX`(ㅡ)를 phone 자원에 추가했다: person 퍼슨, lesson 레슨.
- 활음 보정: `W` + `ㅔ`는 `ㅞ`(west 웨스트), `W` + `ㅗ`는 `ㅝ`(water 워터, work 워크, world 월드).

남은 실패 1건은 **national**이다. 프로토타입은 네이셔널로 읽고 표준은 내셔널인데, 그 차이는
nation → national의 강세 이동에 따른 모음 축소라 자소만 보는 규칙으로는 알 수 없다. 사전에
넣어 통과시키지 않고 실패로 기록한다. 통과하는 17건은 회귀 게이트
(`oov_guess_neighbour_regression_v21.jsonl`)로 묶었다.

게이트는 28 + 30 + 17 = 75건이고, 측정 세트는 76건이다.

## 4차: 동사 활용·자음 뒤 `w`·유성 `s`·고유명사 (2026-09-25)

3차까지의 세트에 없던 것을 채운 27단어를 규칙 변경 전에 작성했다
(`tests/evaluation/oov_guess_form_v21.jsonl`). 기준선 5/27 → 25/27.

| 고친 것 | 방법 | 예 |
|---|---|---|
| 기본 `o`가 늘 `아` | 자소 기본값 `o` → `OW` | logging 로깅, boston 보스턴 |
| 자음 뒤 `w`가 한 음절 | 새 자원 `phone_glide`(기본 `split`, 연구개음만 `merge`) | sweet 스위트, twin 트윈, quick 퀵 유지 |
| 모음 사이 `s`가 무성 | 자소 규칙 `easo`, `easy`, `busy`, `visi`, `^music` | 시즌, 이지, 뮤직 |
| 자소 key 4자 한계 | matcher와 validator 상한을 5자로 | `^reaso` 리즌, `^chica` 시카고 |

`o` → `OW`는 네 세트 전부로 확인한 뒤 바꿨다. 다른 세트에 회귀가 없었다.

자소 key를 5자로 늘린 것은 과적합을 줄이기도 한다. `^chica`는 chicago만 잡고 chicken을
건드리지 않지만, 4자 시절의 `^chic`였다면 chicken을 시킨으로 만들었을 것이다.

## 5차: 다시 이웃 단어 (2026-09-25)

4차가 부른 규칙(`or$`, `ator$`, `um$`, `ves$`, `^music`, `icke`, `^oxid`)의 이웃 24단어를
또 규칙 변경 전에 작성했다(`tests/evaluation/oov_guess_neighbour2_v21.jsonl`).
기준선 15/24 → 24/24. 여기서 `^mus`가 must를 뮤즈트로 만드는 것을 잡아 `^music`으로 좁혔고,
`icke`·`ves$`·`^color`의 값을 고쳤다.

남은 3건은 성격이 다 다르고, 셋 다 사전에 넣지 않고 실패로 남겼다.

- **national** — nation → national의 강세 이동에 따른 모음 축소. 자소만 보는 규칙으로는
  알 수 없다.
- **michael** — 고유명사의 모음은 사전 지식이다 (Michael 마이클 / Michigan 미시간은 철자가
  같은 부분을 공유한다). 고유명사는 추측 대상이 아니라 사전 대상이라는 것이 이 칸의 결론이다.
- **visit** — 기대값 자체가 다툼의 여지가 있다. market 마켓을 만드는 규칙이 visit을 비짓으로
  읽는다. 작성한 참조는 비지트다. 규칙을 비틀면 마켓·로봇이 깨지므로 열어 두고 검수를 기다린다.

## 확인 범위

Debug CTest 123건 통과, sanitizer 단독 실행, browser gate 통과. 외부 영어 표본은 직전
실행과 수치가 같다 — 한국어 전용 변경이라 영어 출력은 바뀌지 않는다. 사전 항목을 늘려 이
목록을 통과시키지 않았다.

127단어 중 124건이 맞았다는 것은 **이 127단어**에 대한 결과다. 세트는 여전히 명사·형용사 위주이고
동사 활용, 고유명사, 축약형, 하이픈 합성어, 6음절 이상은 표본이 없다. 3차 세트에서 본 것처럼
새 규칙은 이웃 단어를 망가뜨릴 수 있으므로, 규칙을 추가할 때마다 그 규칙의 이웃을 먼저
측정해야 한다. 아직 남은 것으로 확인한 예: national 네이셔널(강세 모음 축소),
season 시슨(모음 사이 `s`의 유성음화), sweet 쉬트(자음 뒤 `W`), walk 왤크.
