# 금융 발음 사전 확장과 검토 기준

이 문서는 금융 사전의 **영문 → 한글 발음 표기**를 관리한다. 금융 용어의 뜻을
번역하거나 금융상품을 설명하는 사전이 아니다. `NAV`는 `엔에이브이`로 읽으며,
그 의미에 해당하는 한국어 용어로 바꾸지 않는다.

## 이번 추가분

- 원본: [finance-additions.jsonl](../lexicons/ko-KR/finance-additions.jsonl)
- 출처 목록: [finance.json](../lexicons/sources/finance.json)
- 확인일: 2026-09-16
- 항목 86개, 별칭 2개를 포함한 조회 키 88개
- `source-checked` 19개, `pending` 67개
- 새 항목 중 46개는 알파벳 이름을 이어 읽는 약어다.

이 46개 약어는 원본의 `scope: "finance"`로 금융 전용 리소스에 배치한다.
일반 사전에 항상 켜 놓으면 소문자 영어 `per`, `roe`, `abs`까지 금융 약어로
읽을 수 있기 때문이다. 웹 도구의 금융 어휘 프로필은 이 발음 사전만 켜며,
숫자 식별자를 한 자리씩 읽는 기존 금융 TN 정책을 함께 켜지 않는다.
나머지 신규 단어와 복합어는 일반 시스템 발음 사전에서 사용한다.

기존 사전의 `fintech`, `portfolio`, `hedge`, `swap`, `spread`, `broker`,
`wallet`, `cashback`, `credit`, `debit`, `default`, `benchmark`와
`Bank of America`, `Goldman Sachs`, `Morgan Stanley`는 중복 등록하지 않았다.
대소문자 차이는 새로운 단어로 세지 않는다.

이번 데이터는 설명 문장이나 외부 사전 전체를 가져오지 않고, 필요한 단어의
표기를 개별 대조하여 작성했다. 약어를 명시적으로 등록하면 읽기 정책을 쉽게
검토할 수 있으나, 기존 철자 읽기 fallback과 결과가 같은 약어도 있다. 항목 수
증가를 그대로 새로운 발음 정확도 향상으로 해석하지 않는다.

## 출처 확인이 의미하는 것

`source-checked`는 연결한 공식 자료에서 해당 한글 표기를 확인했다는 뜻이다.
사람의 승인, 음성 평가 통과, 모든 문맥에서의 정답을 뜻하지 않는다. 출처의
경제 설명과 정책이 현재도 유효한지 판단하는 용도로도 사용하지 않는다.

예를 들어 `REITs → 리츠`는 [국토교통부의 리츠 소개](https://reits.molit.go.kr/pub/intro/info/infoReits01?pmn=4),
`SPAC → 스팩`은 [금융위원회 자료](https://fsc.go.kr/po010106/71445),
`covered bond → 커버드본드`는 [금융위원회의 커버드본드 자료](https://www.fsc.go.kr/po010106/73526)에서
대응 표기를 확인했다. `BlackRock → 블랙록`은
[회사 자체 한국 홈페이지](https://www.blackrock.com/kr)의 이름을 따른다.

공식 자료에도 표기 흔들림이나 오기가 있을 수 있다. 한국은행의
[스태그플레이션 게시물](https://www.bok.or.kr/portal/bbs/P0000795/view.do?menuNo=200560&nttId=167374)은
제목과 본문의 표기가 다르다. 이 사전은 영문과 함께 나온 본문의 `스태그플레이션`을
채택하고 그 판단을 레코드에 적었다. 출처 URL이 있다는 이유만으로 무조건
자동 승인하면 안 된다.

`pending`은 현재 프로젝트에서 사용할 수 있는 발음 초안이다. 실제 고객 문장과
담당자의 선호를 바탕으로 검토해야 한다. 특히 공식 문서에 `ETF`라는 영문 약어가
나온다는 사실만으로 `이티에프`라는 한글 읽기가 그 출처에서 검증되었다고
표시하지 않는다. 사전의 pending 항목은 고객 배포 전에 필터링하거나 개별 승인할
대상이며, 기본 개발 리소스에 포함되었다는 사실이 production 승인을 뜻하지 않는다.

## 약어와 표기 선택

| 항목 | 현재 선택 | 검토할 점 |
| --- | --- | --- |
| ETF, ETN | 이티에프, 이티엔 | 알파벳 이름 읽기. 뜻을 풀어 번역하지 않음 |
| NAV | 엔에이브이 | 순자산가치로 치환하지 않음 |
| PER, CAGR | 피이알, 씨에이지알 | 업계에서 단어처럼 읽는 변형은 고객 사전에서 선택 |
| REITs, SPAC | 리츠, 스팩 | 공식 자료에서 쓰는 단어식 한글 표기를 채택 |
| ISA, ABS, CD, CP, PF, FX | 철자 이름 읽기 | 다른 분야에서도 쓰이므로 문맥 검토 필요 |
| cash flow | 캐시 플로 | 플로/플로우의 고객 선호 확인 필요 |
| credit default swap | 크레디트 디폴트 스와프 | 기존 `credit`, `swap` 사전 선택과 일치. 크레딧/스왑 변형 검토 가능 |
| capital, venture capital | 캐피털, 벤처 캐피털 | 특정 회사의 상호가 캐피탈이면 해당 전체 상호를 별도로 등록 |
| JPMorgan | 제이피모간 | 회사가 사용한 제이피모간 표기를 선택. `JP Morgan`은 공백 별칭 |
| high yield | 하이일드 | `high-yield`도 같은 발음으로 선택한 별칭 |

영어 문맥에서는 이 사전을 적용해 한글화하지 않는다. 대소문자만으로 모든
영문 약어의 의미를 판별할 수 없으며, 현재 사전은 품사나 금융 세부 의미를
분기하는 완전한 문맥 사전이 아니다. 예를 들어 소문자 일반 영어 `abs`와
금융 약어 `ABS`는 현재 대소문자 무시 조회에서 동일한 키가 된다. 이런 충돌은
실제 입력 수집과 문맥 규칙 또는 도메인별 리소스 분리로 검토해야 한다.

## 사람이 수정할 때

1. 원본 JSONL에서 해당 `term`의 `pronunciation`을 수정한다. 한 줄에 한 객체를
   두고 탭이나 줄바꿈을 발음 문자열 안에 넣지 않는다.
2. 공식 표기를 확인했다면 `evidence`에 `finance.json`의 출처 ID를 연결하고
   `notes`에 확인한 표기와 선택 이유를 적는다. 뜻풀이, 긴 인용문은 넣지 않는다.
3. 확인하지 못한 항목은 `pending`으로 유지한다. 회사의 선호 발음이나 사람의
   승인을 출처 대조와 혼동하지 않는다.
4. 별칭은 실제 입력에서 쓰이는 다른 철자나 공백 형태에만 추가한다. 대소문자만
   다른 별칭이나 수량을 늘리기 위한 변형을 만들지 않는다.
5. 아래와 같이 한국어 조사와 함께 쓰는 문장, 영어 보존 문장, 사전 override,
   여러 입력 청크에서의 스트리밍 결과를 함께 검토한다.

컴파일, 리소스 적용 및 검증의 공통 절차는
[리소스 수정 가이드](resource-editing-guide.ko.md)를 참고한다. 한 고객의 읽기를
바꾸기 위해 모든 고객에게 적용되는 system 사전부터 바꾸지 말고, 적용 범위가
고객별인지 공통 기본값인지 먼저 기록한다.

## 직접 작성한 검토용 문장

다음 기대 출력은 엔진 실행 결과를 복사하지 않고 사전의 선택 정책에 따라
작성한 텍스트 기준이다. 약어 예문은 금융 어휘 프로필을 켠 상태를 기준으로 한다.
독립된 사람의 검토가 완료된 평가 자료는 아니다.
문장 전체의 금융 사실 판단이나 투자 안내를 평가하지 않는다.

| 입력 | 기대 출력 |
| --- | --- |
| ETF의 수수료를 확인하세요. | 이티에프의 수수료를 확인하세요. |
| NAV를 확인하세요. | 엔에이브이를 확인하세요. |
| DSR을 확인하세요. | 디에스알을 확인하세요. |
| REITs에 관한 안내입니다. | 리츠에 관한 안내입니다. |
| SPAC을 설명합니다. | 스팩을 설명합니다. |
| leverage를 낮춥니다. | 레버리지를 낮춥니다. |
| duration을 확인하세요. | 듀레이션을 확인하세요. |
| covered bond를 안내합니다. | 커버드본드를 안내합니다. |
| covered call의 구조를 설명합니다. | 커버드콜의 구조를 설명합니다. |
| high yield를 설명합니다. | 하이일드를 설명합니다. |
| margin call을 점검합니다. | 마진콜을 점검합니다. |
| BlackRock이 발표했습니다. | 블랙록이 발표했습니다. |
| rebalancing을 진행합니다. | 리밸런싱을 진행합니다. |
| crowdfunding을 설명합니다. | 크라우드펀딩을 설명합니다. |

다음 영어 문장은 각각 입력과 출력이 같아야 한다.

```text
Please compare the ETF fees.
NAV changes every day.
The REITs market is open.
BlackRock released the report.
Please explain the covered call strategy.
Fidelity published the fund report.
```

## 다음 검토 우선순위

실제 금융 안내와 콘텐츠 대본에서 사전 미등록 단어 및 선택이 달랐던 단어를
모아 빈도와 영향에 따라 검토한다. 약어 수를 무작정 늘리기보다 상품·회사
고유명, 복합어, 동일 철자의 문맥 충돌, 조사 결합을 우선 확인한다.
사람의 검토 기록과 변경 이력을 쌓고, 출처 확인 상태와 고객의 승인 상태를
별도로 관리해야 production 배포 범위를 정할 수 있다.
