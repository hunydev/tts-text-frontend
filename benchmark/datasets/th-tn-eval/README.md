# 태국어 TN held-out 셋 (th-tn-eval)

프로젝트 소유자 요청(2026-10-14, 태국어 3단계)으로 태국어 팩의 일반화를 재려고 만든 셋이다. **정답을 시스템 출력에 맞춰 고치지 않는다.**

- **마크업:** 중국어·베트남어 셋과 같다.
  - `{원문|읽기}`가 채점 구간이다.
  - `a/b`는 둘 다 정답, `[x,y]`는 하나를 고름(빈 선택 허용), `(x)`는 생략 가능이다.
- **기준 읽기:** 소유자 셋 지시문과 같다.
  - 연도는 쓰인 수 그대로 읽는다. 전화·코드는 한 자리씩 읽는다.
  - 2는 สอง/โท를 함께 받는 곳이 있다.
- **빌드:** `python3 -I benchmark/datasets/th-tn-eval/build.py heldout`
- **측정:** `python3 -I benchmark/evaluators/thai_tn_eval.py run|score --set heldout [--system ours|ours-ko|ours-en|raw]`. 결과는 `benchmark/generated/th-tn-eval/`(로컬 전용)에 둔다.
- **채점:** NFC로 맞추고 소문자로 바꾼 뒤, 공백·문장부호·기호를 지운다. 구간 읽기 중 하나가 앞 구간 뒤에 순서대로 나오면 맞은 것으로 센다.

## Held-out v1 (th-tn-heldout-v1, 250문장, 채점 구간 297개, 18개 범주)

- **작성:** 팩과 소유자 셋을 보지 않은 Claude 하위 에이전트 둘이 썼다(저장소 접근 없음).
  - A: 생활·뉴스·여행·음식·건강·스포츠 125문장
  - B: 기술·과학·상거래·금융·교육·행정·의료 125문장
- **검수:** 원어민 검수(Claude)로 세 곳을 고쳤다.
  - [หนึ่ง,]ล้าน: หนึ่ง 생략을 ร้อย·พัน과 같게 받는다.
  - `1 1/2`의 หนึ่งจุดห้า: 쓰인 꼴의 읽기가 아니라서 지우고, เศษ 꼴을 더했다.
  - `TG 628`의 2: 다른 작성자처럼 สอง/โท를 받는다.
- **중복:** 소유자 셋·계약과 겹치는 문장은 없다.
- **고정:** 3단계 1차 코드를 e578bf3으로 고정한 뒤 처음 쟀다.
- **결과 (구간):**

  | 시점 | 태국어 요청 | 한국어 요청 | 원문 그대로 |
  |---|---|---|---|
  | 첫 측정 | 81.5% | 71.4% | 0.3% |
  | 3단계 수정 뒤 | 94.6% | 94.6% | |

  - 수정 뒤에는 개발용 셋이므로 일반화 측정에는 v2가 필요하다.

## 소유자 v2 (owner2, 실제 문장 371개, 채점 구간 735개, 2026-10-15)

- **출처:** 프로젝트 소유자가 준 `tn-eval/th-TH-v2.zip`이다. scb-mt-en-th-2020 태국어 쪽 실제 문장에 정답을 단 셋이다.
- **보관:** CC BY-SA 4.0이라 저장소에는 넣지 않는다. `benchmark/generated/th-owner/th-TH-v2/`에 풀고 `build.py owner2`로 `benchmark/generated/th-tn-eval/th-tn-owner-v2.jsonl`을 만든다.
- **빌드 규칙:** `skip` 2줄은 뺀다. 빈 선택지(`{/|[ทับ,สแลช,]}`, 기호를 읽지 않아도 됨)는 받는다.
- **결과 (구간):**

  | 시점 | 태국어 요청 | 한국어 요청 |
  |---|---|---|
  | 고정 코드(23573ba)로 첫 측정 | 87.5% | 86.5% |
  | 4단계 후 | 96.1% | 95.9% |

  - 첫 측정에는 엔진 오류가 1건 있었다. 이제 개발용이다.
