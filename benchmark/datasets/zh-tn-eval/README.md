# 중국어(간체) TN 평가셋 v1 (zh-tn-eval-v1)

프로젝트 소유자 요청(2026-10-11)으로 중국어 팩 0단계 측정을 위해 직접 작성한 평가셋입니다. 원문과 정답 읽기를 한 쌍으로 묶은 엔트리 322개, 채점 구간 346개입니다.
기본형보다 어려운 경우(二/两, 번호 읽기, 범위 표기, 단위 기호, 수식 등)를 촘촘히 넣어 빈틈을 찾는 용도입니다. **정답을 시스템 출력에 맞춰 고치지 않습니다.**

- 원본: `src/*.txt`(사람이 읽고 고치는 마크업), 빌드 결과: `zh-tn-eval-v1.jsonl`
- 빌드: `python3 -I benchmark/datasets/zh-tn-eval/build.py`
- 측정: `benchmark/evaluators/chinese_tn_eval.py` (사용법은 파일 머리말). 결과는 `benchmark/generated/zh-tn-eval/`(로컬 전용)

## 마크업

일본어 평가셋(`ja-tn-eval`)과 같습니다. `{2个|两个}`는 원문 `2个`, 정답 `两个`인 채점 구간입니다. `a/b`는 둘 다 정답, `[x,y]`는 하나를 고름(빈 선택 허용), `(x)`는 생략 가능합니다.
정답 표기는 간체 한자이고 숫자는 한자 숫자로 씁니다. 라틴 문자(iPhone, G, K)는 그대로 둡니다. 전화·코드의 1은 幺와 一를 모두 허용합니다.

## 범주 (20개)

cardinal, liang(二/两), year, decimal, currency, percent, fraction, negative(음수·온도), range, time, date, unit, ordinal, ratio(점수·비율), approx(余·多·来), code(전화·번호), latin(영숫자), math, address, mixed(여러 구간 문장).

## 채점

출력과 정답을 NFKC로 접고, 소문자로 바꾸고, 〇은 零, 圆은 元(같은 발음)으로 보고, 공백과 문장부호를 지운 뒤, 구간 읽기 중 하나가 앞 구간 뒤에 순서대로 나오면 맞은 것으로 셉니다.
중국어 출력은 한자라 일본어처럼 리더(가나 변환)를 거치지 않습니다.
