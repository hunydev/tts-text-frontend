# 베트남어 TN 평가셋 (vi-tn-eval)

프로젝트 소유자 요청(2026-10-13)으로 베트남어 팩 1단계를 측정하려고 만든 평가셋이다. **정답을 시스템 출력에 맞춰 고치지 않는다.**

- **마크업:** 중국어 평가셋(`zh-tn-eval`)과 같다.
  - `{원문|읽기}`가 채점 구간이다.
  - `a/b`는 둘 다 정답, `[x,y]`는 하나를 고름(빈 선택 허용), `(x)`는 생략 가능이다.
- **기준 읽기:** 북부 표준어다.
  - 남부식 변이(ngàn, lẻ, nhăm)와 tư, mùng·mồng은 함께 받는다.
  - 라틴 글자는 그대로 둔다.
- **빌드:** `python3 -I benchmark/datasets/vi-tn-eval/build.py [eval|heldout]`
- **측정:** `benchmark/evaluators/vietnamese_tn_eval.py run|score --set eval|heldout`. 결과는 `benchmark/generated/vi-tn-eval/`(로컬 전용)에 둔다.
- **채점:** NFC로 맞추고 소문자로 바꾼 뒤, 공백·하이픈·문장부호를 지운다. 구간 읽기 중 하나가 앞 구간 뒤에 순서대로 나오면 맞은 것으로 센다.

## 개발용 v1 (vi-tn-eval-v1, 150문장, 채점 구간 170개, 13개 범주)

- **작성:** 팩을 보지 않은 Claude 하위 에이전트가 썼다(저장소 접근 없음).
- **마크업 정리:** `[ba mươi (phút),rưỡi]`처럼 선택 안에 생략을 겹친 4곳을 같은 뜻으로 풀었다.
- **교차 확인:** OpenAI gpt-5.4-mini가 같은 문장의 읽기를 따로 썼다. 구간 91.2%가 일치했고, 불일치 15건에 정답 오류는 없었다.

## Held-out v1 (vi-tn-heldout-v1, 240문장, 채점 구간 281개)

- **작성:** 작성자 둘이 썼다.
  - A: 생활·뉴스·여행·스포츠 120문장
  - B: 기술·과학·상업·금융·교육·행정 120문장
- **순서:** 1단계 코드를 b5554c4로 고정한 뒤에 처음 열었다.
- **검수:** 원어민 검수(Claude)와 OpenAI 교차 확인을 했다. 구간 86.1%가 일치했고, 불일치 37행은 모두 모델 쪽 오류였다.
  - 허용 읽기는 라틴 글자 정책에 맞춰 `5G`의 năm G 한 곳만 넓혔다.
- **중복:** 개발용 셋과 같은 문장이 1개 있다(제거하지 않음).
- **고정:** f4c2a1a로 고정한 뒤 측정했다.
- **측정 뒤 정리(2단계에서 개발용으로 쓰면서):** `7h30-11h30`도 개발셋처럼 phút를 받게 했다. 1단계 수치(93.2%)는 이 수정 전의 값이다.
