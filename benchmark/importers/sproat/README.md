# Sproat/Jaitly importer

An original, Python standard library importer for the **original three-column
TSV distribution**, not the separate Kaggle competition CSV format. No upstream
code or corpus text is vendored here. Tests use original synthetic fixtures.

## Acquire a bounded, explicit research sample

From the repository root:

```sh
python3 benchmark/importers/sproat/fetch_sample.py /tmp/ttf-sproat
python3 benchmark/importers/sproat/import_sproat.py \
  /tmp/ttf-sproat/sample-prefix.tsv /tmp/ttf-sproat/sentences.jsonl \
  --source-file en_with_types/output-00058-of-00100 --partial-source
python3 benchmark/importers/sproat/test_import_sproat.py
```

**Read `fetch-manifest.json` before choosing `--source-file`.** The example member
is the member actually observed in Kaggle version 1 on 2026-09-16. Archive member
order is not numerical shard order; the helper records the member it really read.
It requests only the first 1 MiB of the English ZIP-wrapped `.tgz`, requires HTTP
206 with the requested range, bounds each decompression stage to 16 MiB, takes
at most 50,000 TSV lines, and ends at the last complete sentence. It separately
downloads the small distribution README and LICENSE, recording all hashes.

The sample is **a prefix of training shard 58**, not the paper's test split, not a
random sample and not a representative accuracy estimate. The incomplete archive
does not allow verification of its full gzip CRC; the manifest says so. Hashes
identify the received prefix and the extracted local artifact. No claim is made
that they authenticate the complete corpus. Cache outside the Git working tree.

The historical Google Storage URL currently returns 403. The helper uses the
author-linked Kaggle distribution. If its packaging or range support changes,
the helper fails instead of downloading a multi-gigabyte archive. It downloads
no Russian/Polish corpus; local original-format files in those languages can be
imported with `--language ru-RU` or `pl-PL` for future engines.

## Import local source files

```sh
python3 benchmark/importers/sproat/import_sproat.py \
  /path/en_with_types/output-00099-of-00100 /tmp/sproat-test.jsonl \
  --source-file en_with_types/output-00099-of-00100 --limit 1000
```

`--limit` is a deterministic prefix of complete **sentences**, not a random sample
or a token count. The paper's English evaluation is the first 100,002 **lines** of
shard 99; `--limit 1000` is not a reproduction of that evaluation. Default split
inference uses shard 00–89=`train`, 90–94=`dev`, 95–99=`test`; named local files
such as `evaluation` require an explicit `--split` and their original source name
should still be provided for provenance. Hashing reads the local artifact once;
conversion reads it again and keeps only one bounded sentence in memory.

## Mapping to common schema version 1

- One case per complete `<eos><TAB><eos>`-terminated sentence.
- Each token row is exactly `CLASS<TAB>written<TAB>spoken`.
- `text` joins written tokens with one ASCII space. Original inter-token spacing
  is unavailable; this is reconstructed context, not the original raw sentence.
- `<self>` copies the written token; `sil` becomes the empty string. Any other
  reference is preserved **even for PLAIN**. A PLAIN spelling conversion must not
  be replaced with the input merely because its class is PLAIN.
- `expected` joins nonempty spoken values with one ASCII space. No case folding,
  punctuation deletion beyond the explicit `sil` marker, or spelling correction
  is applied to supplied references.
- Every token, including PUNCT and PLAIN, has a span with UTF-8 byte offsets into
  `text`, raw source class, original spoken marker and source line number.
- Source file, split, revision, SHA-256 of the actual local artifact, source URL,
  license evidence and prefix-selection flags remain attached to every case.
- Rows are `reference_status=dataset-reference`, `usage=benchmark-only`.
  These references were generated by Kestrel, not approved by a human reviewer.

Malformed UTF-8/columns, blank or empty sentences, oversized records, and a final
sentence without EOS are errors. `--drop-incomplete` explicitly discards only an
incomplete final sentence. Unknown uppercase source classes are retained rather
than silently skipped. Output replacement is atomic after successful parsing;
an import error does not leave a partial replacement output. A requested limit
intentionally does not validate later, unselected source rows.

Native sentence exact match will penalize punctuation preservation because this
dataset represents most punctuation as silence. Keep it visible and report any
spoken projection as a separately named metric; do not silently rewrite the
reference into the engine's policy. Contextual span comparisons must use the
sentence engine result, not normalize each token alone.
