입력 대기

실제 native 콜백이 발생하는 순서입니다. 시간은 worker 내부 경과 시간이며 네트워크·시작 비용을 제외합니다. 입력 간격을 지정하면 그 대기 시간은 포함됩니다.

실제 입력 write 목록 0회

각 native write 직전의 byte 범위입니다. UTF-8 문자 중간에서 나뉜 입력은 hex로 표시합니다. 화면에는 최근 128회, JSON에는 전체 기록을 담습니다.

발음 제어 표기 문법과 예시는 입력창 아래 제어 구문 도움말에 있습니다. 발화용 출력은 이메일·URL을 읽을 수 있는 텍스트로 바꾸며, 문자 제거 설정은 발화용 출력에서만 적용합니다. 코드·태그·경로는 보호됩니다. 입력 문법·오류·출력 정책 안내 ↗

문장 / 구절 · 입력 청크 설정

길이 목표는 원문 Unicode 문자 수입니다. 구절 분할을 꺼도 최대 길이에 따른 안전 분할은 유지됩니다. 코드·미완성 숫자·인용문은 경계 확정까지 대기할 수 있습니다. 발음 제어 표기는 닫는 중괄호까지 기다리며, 미완성 표기는 마지막 flush에서 오류가 됩니다.

원문 위치로 두 번의 write 구성 입력 텍스트에서 커서를 놓고 누르세요. 위치를 UTF-8 byte로 계산합니다.
