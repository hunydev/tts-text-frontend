TN 비교 · Jev 채점

같은 원문, 여러 TN의 결과를
Jev로 비교하세요.

카테고리별 대표 원문을 각 TN으로 변환한 결과를 채운 뒤, TypeSafe Jev가 결과마다 "원문을 올바르게 읽었는가"를 채점합니다. 참조 정답은 쓰지 않습니다.

평가셋을 불러오는 중입니다.

TN 결과

전체 평가는 채워진 모든 문장을, 수정된 내용만 평가는 아직 채점하지 않았거나 채점 뒤 바뀐 문장만 채점합니다. 문장 표의 행마다 있는 평가 버튼은 그 문장 하나만 채점합니다. 같은 원문·결과 쌍은 캐시에서 바로 답합니다.

가져오기 형식: JSONL {"id": …, "actual": …}, JSON {id: 결과}, TSV id⇥결과(3열이면 마지막 열), TXT(내보낸 원문 순서대로 한 줄에 결과 하나).

Jev 결과 비교

인정: 숫자 값을 코드로 대조해 바뀌지 않았고, 결과에 숫자·로마자·기호가 남지 않았고, TypeSafe Jev가 "결과가 원문을 소리 내어 읽는 올바른 방법"이라고 판단한 확률이 0.7 이상인 문장입니다. ※ 표시 번호류와 앞에 번호·코드·우편 같은 말이 있는 번호는 Jev가 자리별 대조를 하지 못하므로, 값 대조가 일치하고 번호를 한 자리씩(뒤에 '번'이 오면 하나의 수로도) 읽었으면 인정합니다. 금액처럼 읽은 번호와 글자 이름으로 읽지 않은 아이디 로마자는 Jev 기준입니다. 불인정: 값 불일치, 원문 표기 남음, Jev 0.3 미만. 확인 필요: 그 밖(Jev 0.3~0.7). 괄호 안은 Jev만으로 판정한 이전 기준(0.7)의 인정률입니다.

사람 판단과 비교

문장 표의 맞음·틀림 버튼으로 결과가 맞는지 직접 판단하면, 그 판단이 원문·결과 쌍마다 저장되고(모든 시스템 공통) 아래 표에서 자동 판정과 비교됩니다. 모인 판단으로 인정 기준과 Jev 질문을 보정합니다.

Jev 질문 구조

채점할 때마다 TypeSafe Jev에 보내는 요청 그대로입니다. <원문>과 <TN 결과> 자리에 문장이 들어가고, Jev는 판정 기준이 참일 확률(noul, 0~1)을 돌려줍니다.
