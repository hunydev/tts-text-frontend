금융·콘텐츠 용어의 읽기와 출처를 살펴보고 수정안을 실제 엔진으로 시험합니다.

사전을 불러오는 중입니다.

사전 현황

출처 대조는 문서에 있는 표기를 확인한 상태입니다. 독립적인 사람의 발음 검수 완료와는 다릅니다. 임시 선택값과 복수의 읽기 가능성도 함께 표시합니다.

근거 자료

    검사 결과가 여기에 표시됩니다.

    시험과 다운로드는 서버의 사전을 변경하지 않습니다. 반영할 수정안은 사전 관리 가이드에 따라 원본에 기록하고 검증합니다.

    입력 문서의 사전 사용 현황

    Coverage

    실제 원고를 넣으면 직접 사전 적중과 fallback에 의존하는 용어를 분리합니다. 적중률은 발음 정확도 점수가 아닙니다. 

    검사할 원고를 입력하세요.

    영어 문맥·보호된 코드·숫자 정규화는 발음 사전 적중률에서 제외합니다. 입력은 서버에서 처리하며 원고를 외부로 보내거나 서버 파일로 저장하지 않습니다.
